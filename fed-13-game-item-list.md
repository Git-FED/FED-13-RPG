# FED-13 RPG - Game Item List

One single item list for FED-13 RPG. This file combines the item system, the Quartz and Arts items, and the transportation items and materials into one list, deduplicated.

## Rules this list follows

- Character is the trainer. Creatures are Bondkin. Monsters are Pokemon-like Feral. Creatures and monsters get used like Pokemon in battle, but are treated different outside of battle.
- Single battles are normal Pokemon style battles. Anything after that, 2v2 and up to 6v6, is grid turn based team style battle.
- Items structure: character items, class items, and role material for collecting material are separate categories. Character tools are separate from creature items, categorized by the FFTA item listing. Monsters do not have weapons or equipment, instead they have monster related items.
- The Lattice, with Shards and Core Shards, is for the CHARACTER, not Bondkin. Arts will not get to be used as often, and there will be more passive or healing Arts than attack Arts.
- Every item is graded: F 0, E 1-21, D 22-51, C 52-79, B 80-99, A 100-139, S 140-169, SS 170-199, SSS 200-249, SSSS 250+. No scoring formula is given in the sources, so none is given here.
- Currency is unnamed in the sources. No currency name, no price list, and no earning rules are given here. Prices below are only given where a source states one, in that source's own currency (mira, gil, Silver, Recycled Material, sepith, U-Material).
- An item is listed once, in its main category, and cross-referenced from other categories. Counts below count each named item once.
- If a source is unverified, the entry is flagged UNVERIFIED. If a category has no source items, this file says so plainly and does not fill it.
- Arts are not items. Only Art quartz, Core Shards, and Arts-related items are listed in section 7. For the full Art lists, see the Arts files for Trails of Cold Steel 1, 2, and 3.

## Counts, approximate

Total named items in this file: about 450, counting each named Gummi block, each named Art quartz, and each named Core Shard once. The count is approximate because some entries are categories (for example "weapon"), some names appear as both an item and a vehicle, and some source lists are incomplete. Breakdown by section: 1 Character Items about 20, 2 Class Items 0 new named items, 3 Role Material about 13, 4 Character Tools about 11, 5 Bondkin / Creature Items about 3 new named items plus gear categories shared with section 1, 6 Monster Items about 4 new named items, 7 Quartz / Lattice / Arts Items about 190, 8 Transportation Items and Materials about 200, 9 Consumables / Healing / Food / Water about 5 new named items, 10 Synthesis / Crafting / Materials about 6 new named items plus cross-references, 11 Mission / Key Items about 9 new named items.

## 1. Character Items

For the trainer only, cap 150. Character gear is upgradable with U-Materials. Sources: Puffkin shops, mission rewards, trade shop, treasure chests, New Game Plus carry-over.

### 1.1 Weapons, character

No individual named weapon is given in the sources, only categories. Each category is one entry here.
- Sword: character weapon category. Opening choice: Sword, Shield, Staff. The opening choice affects the main player.
- Blade: character weapon category.
- Saber: character weapon category.
- Staff: character weapon category. Opening choice item, see Sword.
- Dagger: character weapon category.
- Katana: character weapon category.
- Spear: character weapon category.
- Axe: character weapon category. Note: Axe is also a gathering tool, see section 4.
- Bow: character weapon category.
- Gun: character weapon category.
- Fists: character weapon category.
- Soulblade: the main player weapon. Equippable and upgradable. How it is first obtained and its upgrade steps are not given in the sources.
- Elemental weapon: elemental weapons carry elemental weakness and resistance. Elements: Earth, Fire, Wind, Water, Time, Space, Mirage, plus Dark (Hollow variants) and Ghost (Echo variants). Which weapon carries which element, and how much weakness or resistance it gives, is not given in the sources.

### 1.2 Armor and accessories, character

- Shield: character armor category. Also an opening choice item, see Sword.
- Armor: character armor category.
- Elemental armor: elemental armor carries elemental weakness and resistance. Same element note as Elemental weapon above.
- Shoes: character gear category, upgradable with U-Materials.
- Gloves: character gear category.
- Accessories: character gear category, upgradable with U-Materials. Costumes are collected in the same way, see below.
- Costumes: collected as gear. Costume and accessory collecting is part of the character equipment system. No individual costume pieces are named in the sources.

### 1.3 How character gear is obtained and used

- Puffkin shops sell items, weapons, armor, and accessories, and host synthesis.
- Weapons and gear also come from shops, mission rewards, and trade shop.
- New Game Plus carries equipment over after clearing.
- Buying a certain weapon can let the holder use a certain skill, under the item to attack rule. Which weapon grants which skill is not given in the sources.
- Equipment slots exist for the character and for Bondkin. How many slots each has, and which slot takes each gear category, is not given in the sources.

## 2. Class Items

For the character's class only. Class flow: Class, Advanced Class, Twin Path, Twin Ascension. Twin Path is a second character class at once, after Advanced Class. Twin Ascension is two advanced character classes at once.

No individual class item is named in the sources. This section is kept separate because character items, class items, and role material are separate categories, but there is no separate named class-item list to fill it with, so this file does not invent one.

What is known:
- Opening choice items, Sword, Shield, Staff, are listed in section 1. They are character items that affect the main player.
- Class weapons and class gear are the character weapons and armor in section 1, used by the character's class. No item is named as belonging to one class only.
- Crafts are character specific techniques costing CP. CP is built by attacking and taking damage. S-Crafts are super moves, 100+ CP, stronger at 200+ CP. S-Break can be pressed anytime at 100+ CP. No CP-restoring consumable item was found in the sources.

## 3. Role Material

For collecting material only. Roles belong to the character, not to Bondkin. Bondkin have Paths. Roles never affect Bondkin, and Bondkin jobs never affect roles. Named roles: Logger, Miner, Gatherer, Hunter, Chef, Angler, Scavenger, Firearms Master. The sources say 10+ roles, so more roles exist but their names were not given. Role XP example: chop wood gains Logger points, level up as Logger to Master Logger one day. What each role grants as it levels is not given in the sources.

Materials, what they are for, who they are for, how you get them:
- Wood: building and crafting material. Character, Logger role. Chop trees. Also 150 Wood to craft a Mechanic Station, see section 8.
- Stone: building and crafting material. Character, Miner role. Break stones. Also 75 Stone to craft a Mechanic Station.
- Ore: crafting material. Character, Miner role. Mine stone and ore.
- Iron ore: crafting material. Character, Miner role. Mine stone and ore.
- Copper ore: crafting material. Character, Miner role. Mine stone and ore.
- Plants: gathering material. Character, Gatherer role. Harvest plants.
- Fish: food and crafting material. Character, Angler and Hunter roles. Fish with a fishing rod.
- Cedar bark: crafting material. Character. Cut trees. UNVERIFIED as a per-vehicle recipe, see section 8.
- Ash branch: crafting material. Character. Cut trees. UNVERIFIED as a per-vehicle recipe, see section 8.
- Tattered animal skin: crafting material. Character, Hunter role. Gathering and hunting. Also dismantled in a Deconstruction Bench for Recycled Material.
- Flaxseed: gathering material. Character, Gatherer role. Gathering. Also dismantled in a Deconstruction Bench for Recycled Material.
- Circuit boards: crafting material. Character. Found in mystery boxes on the map, or crafted from steel sheets and wires. UNVERIFIED as a per-vehicle recipe.
- Metals, generic: crafting material. Character. Listed as a crafting material only, no specific metal item named for a specific recipe.

No per-biome resource list was given in the sources. Which resource comes from which biome is not given here.

## 4. Character Tools

Character tools are separate from creature items. No tool in this section is a Bondkin item or a monster item.
- Axe: gathering tool. Character, Logger role. Chop wood.
- Pickaxe: gathering tool. Character, Miner role. Mine stone and ore.
- Fishing rod: gathering tool. Character, Angler role. Fish.
- Workbench: crafting station. Character, homestead. Required to craft: no workbench, no crafting. Crafts weapons, armor, drones, unfinished goods, weapon attachments, equipment modification materials, modified modules, and Repair Parts. Not a vehicle crafter.
- Construction Workbench: primary workbench. Character, homestead. Crafts all other workbenches and furniture, including the Mechanic Station. Place first at the homestead.
- Raw Material Workbench: refining station. Character, homestead. Refines gathered raw materials into usable crafting items. Without it raw materials cannot be used for crafting or trading.
- Deconstruction Bench: dismantling station. Character, homestead. Dismantle unwanted materials to Recycled Material currency. Obtained via Adventure Guidebook / main story.
- Equipment Repair Table: repair station. Character, homestead. Repairs weapons, armor, drone, gas mask only, not vehicles. Craft at Construction Workbench.
- Mechanic Station: vehicle station. Character, homestead. Crafts vehicles (bikes and four-wheeled vehicles) and repairs all vehicles / restores durability. Craft at Construction Workbench, furniture tab: 150 Wood + 75 Stone, then place at homestead. Also said to be obtained through story progression. Homestead level gates its build formula.
- Homestead Sign: homestead upgrade point. Character. Upgrades happen at the Homestead Sign outside the home. Homestead levels gate character level: Lv1 caps character at level 15, Lv2 unlocks to level 25, farmland active at Lv3, relocate available at Lv2.
- Storage cabinet: homestead storage. Character. The backpack holds a fixed amount, a storage cabinet at the homestead stores extra. How much extra a cabinet holds, and how many cabinets a homestead can have, is not given in the sources.

## 5. Bondkin / Creature Items

For Bondkin only, the trained partner, cap 200. Categorized by the FFTA item listing. Bondkin learn ALL action, reaction, support, combo, and movement abilities from weapons and accessories. A Bondkin equips only one ability and one skill at a time, one passive and one active, abilities cost AP to equip. Every skill use takes a turn. Which weapon grants which skill, AP costs, and whether a learned skill stays after the gear is removed, are not given in the sources.

Bondkin gear categories are the same weapon, armor, shoe, glove, and accessory categories listed in section 1. They are not counted twice here. Bondkin gear is separate instances from character gear: character gear and Bondkin gear do not cross over.

Named Bondkin-specific items:
- Growth Item: to train and grow Bondkin. Found in the Monster Bank, shops, missions. What it does in detail, which stat or level effect, how much, and when it can be used, is not given in the sources. Also listed in section 6 as a training item.
- Soul: Morpher item. A Hunter captures a Feral, it goes to The Bank, it drops a Soul, a Morpher-type Bondkin equips the Soul and morphs into that monster type in battle, with power tied to Bank feeding. Morpher forms, 9 types: Goblin, Flan, Bomb, Dragon, Lamia, Bug, Panther, Foulbloom, Floateye. Morph learned per type, 200 AP each in the source system.
- Satyr Flute: Animist instrument. Character, Bondkin item. Learned from Satyr Flute: Chocobo Rush, 300 AP, 12 MP, 45 WATK, Double Line, a chocobo stampede attack, not transport.
- Bell: Beastmaster instrument. Bondkin, Elderkin only in the source system. Control command, learned from instruments, bells, flutes, harps. Control types, 13: Goblin, Flan, Bomb, Dragon, Lamia, Bug, Grudgeknife, Panther, Foulbloom, Floateye, Undead, Fairy, Rockbeast. Control is not transform, not capture. It controls an enemy monster's actions for a turn.
- Flute: Beastmaster instrument, see Bell.
- Harp: Beastmaster instrument, see Bell.
- Totem Spirit: a guardian special attack for a Bondkin bloodline. Each bloodline gets a Totem Spirit. A Totem Spirit attack is a special attack, a move a Bondkin can use while Mega evolved, or as a Z-move if Mega is not used. Totem Spirits are Stage 3 only. The 5 Totem Spirit names are not given in the sources. Also listed in section 11.

No other Bondkin-specific item is named in the sources. In particular, no individual Bondkin weapon, armor piece, shoe, glove, or accessory is named, only categories.

## 6. Monster Items

For monsters only, wild Feral. Monsters do not have weapons or equipment. They have monster related items only.

Named monster items:
- Monster Egg: monster breeding egg. Monsters can be bred like animals for eggs. A monster egg is bred, then hatched. No named egg item beyond the generic monster egg is given in the sources for FED-13 monsters.
- Growth Item: to train and grow a monster after catch, as a Bondkin. See section 5. Found in the Monster Bank, shops, missions.
- Soul: dropped by a captured Feral, see section 5. A Hunter captures a Feral, it goes to The Bank, it drops a Soul.
- Chocobo Egg: a monster-adjacent mission item in the source system, see section 8. In the source system it is a mission item only, not a mount egg. It is listed here only as a monster-related item, not as a FED-13 monster egg.

Daycare, not Monster Bank, for Bondkin:
- Bondkin do NOT have a Monster Bank. They have a daycare place in the game.
- Monsters are in the Monster Bank. Roster is 24 in The Bank, deploy 6.
- Creatures are different from monsters in breeding: creatures do not lay eggs, they have full children, that can have a high rarity, but it is triple the time it takes a monster egg to be bred than hatched.
- No daycare item is named in the sources. What the daycare does with items, whether a creature left in daycare gains levels or learns moves, whether it needs an item left with it, and whether there is a cost or time rule, is not given in the sources.
- Link trading is a later feature, to be created later. No item for it is given in the sources.

## 7. Quartz / Lattice / Arts Items, Character Only

The Lattice is for the CHARACTER, not Bondkin. Arts will not get to be used as often, and there will be more passive or healing Arts than attack Arts. In the source system, Arts split into Attack, Recovery, and Support. CS3 regular Arts are 25 attack vs 26 recovery/support, near 50/50. Pure recovery is only 11 of 51 in CS3. The FED-13 direction is more passive or healing than attack, which would mean cutting attack Arts and/or adding passive/healing ones. It is not the source default.

The Lattice slots: in the source system, ARCUS II has 7 regular Shard slots plus 2 Core Shard slots, Main and Sub. Main: 100% EXP, full stats, all special abilities. Sub: 50% EXP, first ability only, reduced stats. Slot layout varies per character.

Electric is not a source-system element, it is a FED-13 addition.

### 7.9 Shard synthesis, costs

- Where: Orbal Factories, Orbal Workshops, Charging Stations in CS3. Orbal Factories in CS1/CS2, plus Trade Shops for Rare, Super Rare, and special Shards.
- Base Art Shard cost, CS3 example: Needle Shoot 50 Earth sepith, Ivy Nail 100, Megalith Fall 200, Gravion Hammer 400.
