# FED-13 RPG Effect Prompts

One animation prompt per effect in FED-13 RPG. Paste one prompt as-is into an animation generator to make that effect. The last game reused one look for everything, so every prompt here has its own motion, color, particles, light, impact, timing, and camera. Total: 171 prompts, 129 original plus 42 EX Arts and Lost Arts added 2026-11-22. No prompt describes a weapon, item, or character from any other game. All weapons and items are FED-13 originals, no Keyblades, no weapons from other games.
